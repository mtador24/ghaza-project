
# منصة دعم غزة

## كيفية تشغيل المشروع

### تثبيت التبعيات
```bash
npm install
```

### تشغيل واجهة الويب والخادم معًا
```bash
# في نافذة طرفية واحدة (يبدأ الخادم والواجهة معًا)
npm run dev
```

### تشغيل الخادم فقط
```bash
# في نافذة طرفية منفصلة
node server.js
```

### تشغيل واجهة الويب فقط
```bash
# في نافذة طرفية منفصلة
npm run dev:frontend
```

## ملاحظات هامة

- يتصل التطبيق بقاعدة بيانات MySQL حقيقية
- يستخدم واجهة API REST للتواصل بين الواجهة والخادم
- يمكن الوصول للواجهة على: http://localhost:8080
- يمكن الوصول لـ API على: http://localhost:3001/api
